# Как установить лаунчер?
1. Открываете ссылку https://github.com/mortany/ZNTK_Launcher/releases/latest
2. В выпадающем списке ищите "Release.zip"
4. Качаете этот файл
4. Разархивируйте папку в любое удобное для вас место
5. Запускаете ZNTK из папки. Внимание - для работы требуется запущенный Steam!
